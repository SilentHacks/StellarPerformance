Dependency and presentation update

• Removes required SDModKit and Sandbox Menu dependencies. SDModKit support stays optional.
• Shorter mod-manager description and cleaner documentation.
• Same five optimisations and settings as 1.0.0.

Requirements
StellarDrive Demo 0.8.2, MelonLoader 0.7.3, Windows. SDModKit is optional; Sandbox Menu is not required.

Install
Close the game. Use Stellar Mod Manager, or extract StellarPerformance.zip into the game folder after installing the requirements.

Compatibility
Native simulation and visual refresh rates are retained. Room gas rounding can differ slightly. No new performance measurements.

Settings, benchmarks and validation details are in the repository README.
