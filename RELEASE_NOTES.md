Stellar Performance 2.0.0

• Choose Faithful, Balanced, Performance, Aggressive or Custom with F8 or the menu. Apply and save settings during play.
• Balanced keeps native presentation. Higher levels offer graded cosmetic reductions while retaining the landscape, shadows and readouts.
• Keep fixed meshes batched after hover/highlight interactions, and spread batch construction across frames.
• Cull offscreen part UI and reuse signal connection scans.
• Reduce identical supported replication payloads while retaining native calculations and genuine updates.
• Fix sky and clouds drawing over scenery when contours are reduced.

Simulation and physics keep native rates. Incremental-room gas rounding can differ slightly. Experimental reliable Steam retry and diagnostics are disabled by default.

The mod listing now declares AI usage as vibecoded, development as active, and includes descriptive tags.

Requirements
StellarDrive Demo 0.8.2 and MelonLoader 0.7.3 on Windows.

Install
Use Stellar Mod Manager, or close the game and extract StellarPerformance.zip into the game folder.
